# Ragdoll Sandbox

Следующий кандидат для автоматизации QA мобильной 3D-игры. Сценарий ещё не выбран, игровых прогонов нет. Общий мост находится в `tools/android/android_qa.py`.

Перед практической частью определить:

1. Реальный пакет и версию Android-билда.
2. Одну короткую повторяемую проверку и одинаковую стартовую сцену.
3. Видимый критерий завершения и признаки ошибки.
4. Требуется ли одновременное управление несколькими касаниями.
5. Какие результаты можно подтвердить по скриншотам, а для каких нужна телеметрия игры.

Результаты будущих попыток хранить локально в `runs/ragdoll-sandbox/`. Соблюдать корневой AGENTS.md: сейчас разрешена подготовка; тесты и взаимодействие с устройством отложены.
