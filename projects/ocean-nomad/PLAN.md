# План развития Unity QA

Текущая задача — перенос и стабилизация уже изученных навыков. Состояние и подтверждения — [AGENT_HANDOFF](../../docs/AGENT_HANDOFF.md), запуск — [ONBOARDING_RUN](../../brain/agents/ONBOARDING_RUN.md).

1. Воспроизвести установку из чистого clone и проверить память/исполнителей офлайн.
2. По отдельному запросу QA проверить один известный кейс в новой Unity среде.
3. Проверить всю подготовленную цепочку, измеряя полное время от запроса до результата. Команды выполняются и компилируются по мере использования; отдельную предварительную стадию не добавлять.
4. Добавлять новые действия через демонстрацию, проверку фактического результата и апрув. Навыки переиспользуются между миссиями.
5. Улучшать наблюдаемость, восстановление после транспорта, отчёты и запуск на выделенной Editor машине.

Точное устройство памяти — brain/MEMORY.md; новые факты сохраняются по brain/KNOWLEDGE_WORKFLOW.md. Неподтверждённые возможности остаются отдельно от готовых исполнителей.
