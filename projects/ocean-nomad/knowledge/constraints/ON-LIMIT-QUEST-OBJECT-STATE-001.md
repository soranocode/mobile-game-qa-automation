# ON-LIMIT-QUEST-OBJECT-STATE-001 — повтор квеста и сохранённые объекты

Игра: Ocean Nomad 2.11.0 dev, Unity Editor. Статус: **provisional**, причина конкретной блокировки подтверждена источниками и runtime22.10.2026. Актуальное состояние23.10 не запрашивалось.

В повторном `hands_collect` подтверждены новый запрос/старт, закрытый диалог и прогресс0/2. Созданы `LogTutotial` и `TrashTutorial`: `IsTaken=false`, `IsEnabledByDefault=true`, но оба неактивны.

Сохранённые `res_collected_log=false` и `res_collected_trash=false` применяются при инициализации новых QuestObject. Предыдущий подбор записывает эти значения; повторный вызов Quests не очищает их. Поэтому поиск и ходьба не исправят отсутствие доступных объектов. Это блокировка исходного состояния для повтора, не доказанный дефект чистого нового выживания.

Диагностика: раздельно фиксировать цель отсутствует / существует неактивной / активна вне кадра / перекрыта / далеко / недоступен Pickup. Только первая проверка полного окружения может заключать «отсутствует»; пустой ограниченный список без данных о покрытии означает unknown.

Принудительное включение объектов или изменение флагов не считать действием игрока и не выполнять молча.
