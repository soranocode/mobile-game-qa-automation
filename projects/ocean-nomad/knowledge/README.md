# Знания об Ocean Nomad

Обновлено23.10.2026. Это общий справочник игры и изученных действий. История запусков остаётся в эпизодах и CURRENT.md. Первое чтение — [короткий индекс](index.json); затем нужная карточка, без загрузки всех файлов.

## Общее знание игры

- **Предметы и сущности:** [учебное бревно и мусор](entities/ON-OBJ-TUTORIAL-RESOURCES-001.md) — UID типа, конкретный экземпляр и сохраняемый объект.
- **Механики:** [подбор рукой](mechanics/ON-MECH-PICKUP-001.md) — наведение, доступность Pickup, контекстная кнопка и подтверждение фактического сбора.
- **Помощь обучения:** [автоматическое наведение камеры](mechanics/ON-MECH-GUIDED-CAMERA-001.md) — действие игры после диалога, которое нужно учитывать отдельно от ручного Look.
- **Начальные условия:** [новое выживание без крюка](world/ON-GAME-NEW-SURVIVAL-001.md) — правило человека и границы применения к существующему сохранению Editor.
- **Пространство:** [плот и вода вокруг](world/ON-WORLD-RAFT-001.md) — координатные системы, спавн ресурсов и позиция взаимодействия на настиле. Обход препятствий ещё не реализован.
- **Управление:** [движение, обзор и фокус](controls/ON-CONTROL-MOVE-LOOK-001.md) — подтверждённые короткие примитивы и границы калибровки.
- **Ограничения:** [сохранённые состояния квестовых объектов](constraints/ON-LIMIT-QUEST-OBJECT-STATE-001.md) — почему повторный вызов квеста может оставить ресурсы неактивными.
- **Наблюдение:** [квест, цели и координаты](observation/ON-OBS-QUEST-WORLD-001.md) — модуль записи0.2.0, доступные данные, системы координат и границы навигации. Проверен технически и на человеческой записи Hook use23.10.

Эти сведения хранятся один раз. Новая миссия использует их по ссылкам; текущие положения объектов не становятся постоянными точками маршрута.

## Миссии и исполняемые навыки

- [wooden_hook](missions/ON-QUEST-WOODEN-HOOK-001.md) → [hook_use](missions/ON-QUEST-HOOK-USE-001.md): сначала крафт крюка, затем вылавливание трёх учебных предметов в любом порядке. [Механика крюка](mechanics/ON-MECH-HOOK-001.md) хранится отдельно. Человеческая демонстрация разобрана; агентного прохождения нет.

- [hands_collect](missions/ON-QUEST-HANDS-COLLECT-001.md) — первый кейс ориентации, подхода и подбора. Последний человеческий пример23.10 завершён со сбором обоих ресурсов руками по подтверждению человека; полный агентный сбор пока не подтверждён.
- [Вызов выбранного квеста](missions/ON-QUEST-START-001.json) — TestGUI → Quests → точный UID → Назад до закрытия. Проверен с подсказками человека; готовый универсальный исполнитель не зарегистрирован.
- [Первые три квеста](missions/ON-QUEST-ONBOARD-001.json) — разбор демонстрации и первого прогона2/3 с помощью человека; это история опыта, не общий справочник механик.
- [Реестр одобренных UI-навыков](ui/ON-UI-SKILLS-001.json) — начало новой игры, главное меню, открытие/проверки настроек. Единый профиль13 UI-проверок реально прошёл; физические эффекты и внешние действия имеют отдельные ограничения.

## UI и общие правила исполнения

- [Чит-панель](ui/ON-UI-DEVTOOLS-001.json): область над сердечком, IMGUI и закрытие через Назад; есть проверенный опыт и неудачи ввода.
- [Настройки](ui/ON-UI-SETTINGS-001.json): каталог элементов, ожидаемые результаты и границы проверок.
- [Вход в игру](ui/ON-UI-ENTRY-001.json), [вступительные окна/Premium](ui/ON-UI-OVERLAYS-001.json), [главное меню](ui/ON-UI-MAINMENU-001.json), [новая игра](ui/ON-UI-NEWGAME-001.json).
- [Новая красная ошибка](ui/ON-UI-ERRORWATCH-001.json): остановить дальнейший ввод и прочитать детали; исключения задаёт человек.

## Как искать и пополнять

Из корня automation-репозитория:

```text
python tools/knowledge/lookup.py hands_collect
python tools/knowledge/lookup.py подбор
python tools/knowledge/lookup.py автонаведение
python tools/knowledge/lookup.py "старт без крюка"
python tools/knowledge/lookup.py --id ON-MECH-PICKUP-001 --read
python tools/knowledge/lookup.py --validate
```

Поиск читает только метаданные; тело карточки загружается по явному ID. Связи раскрываются по необходимости. Это простой файловый механизм, не семантический поиск или готовая MCP-память. Поиск по неизвестным формулировкам может требовать нового алиаса.

При каждом новом знании: найти владельца факта, записать источник/билд/дату и статус, связать с миссией/ограничениями, обновить индекс. Правило подробно описано в [KNOWLEDGE_WORKFLOW.md](../../../brain/KNOWLEDGE_WORKFLOW.md). Код, наблюдение агента, объяснение человека и предположение обозначаются раздельно; повторяемая ошибка не превращается в ожидаемую норму.

Сырые видео, логи, сохранения и приватные исходники игры остаются вне этого Git. Доказательства могут быть доступны только на исходном ПК; ссылка не переносит их автоматически. Наличие документации не означает commit/push или апрув готового навыка.
