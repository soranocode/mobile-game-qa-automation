# Знания об Ocean Nomad

Здесь будут отобранные знания игры для агента. Сейчас подтверждённые игровые механики, маршруты и выполненные миссии не записаны: доступа к Unity и игровых прогонов ещё не было.

По мере получения источников разделять материалы по темам:

- `controls` — управление, камера, взаимодействия и условия ввода.
- `missions` — цели, предусловия, критерии завершения и ожидаемое поведение по требованиям.
- `items` — игровые идентификаторы, названия, назначения и подтверждённые способы получения предметов.
- `mechanics` — правила и ограничения механик с версией и источником.
- `navigation` — подтверждённые ориентиры и навыки перемещения с системами координат.

Название темы не является знанием об игре. Не добавлять выдуманные механики или маршруты для заполнения структуры. Новые документы должны содержать источник, билд/область применимости, статус проверки и связи с противоречащим опытом. Следовать [контракту памяти](../../../brain/MEMORY.md).

Сырые эпизоды, скриншоты, координаты конкретного сохранения и данные аккаунта хранить локально в `runs/` или `brain-store/`. В Git включать только просмотренные человеком материалы без локальных данных. Обновление документа о требованиях требует подтверждения владельца требований; наблюдение агента само по себе его не меняет.
