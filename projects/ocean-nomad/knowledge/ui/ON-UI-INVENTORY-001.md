# ON-UI-INVENTORY-001 — работа с инвентарём

29.10.2026; Ocean Nomad2.11.0dev, Unity Editor. Статус: AGENT_VERIFIED_SCOPED, обучение проверено в текущем сохранении; универсальный prepared handler пока отсутствует. Скорость ограниченного маршрута открытия, выбора Canned, Use и закрытия принята человеком в canned_eat; это не апрув скорости всех операций инвентаря. Это UI навык, не миссия онборда.

## Вход и выбор

HUD `UIHudInterfaceButtonBackpack` → `UIBackpackInterfaceStarter.Open("InventoryInfoNEW")` → Backpack с `UIBackpackView`/`UIInventoryInfoPanelNEW`. Из root-nav доступен `BackpackRootTabHandler`. Закрыть/открыть, выбрать ячейку и прочитать выбранные UID/count/dur подтверждено live. Открытие/закрытие по исходникам может сопровождаться interstitial; это не само окно инвентаря.

Цель задаётся назначением, контейнером и предметом; актуальные ID/геометрия берутся заново. `UIDragItemCell.Cell/Item/Storage`, `SelectionManager.Selected/SelectedIndex/SelectedContainer.Storage` — наблюдение; прямые Select/Put/OnDrag не проверяют UI.

## Подтверждённые действия

- Короткий tap выбирает предмет. Удержание без движения показывает описание; `CraftObjectDescription` ждёт `_longTapTime` в реальных Update (исходный default0.35с). Доказано для Trash и WoodenHook удержанием около1с: до down описания нет, затем title соответствует UID, после up held=false. BeginDrag отменяет ожидание/скрывает описание. Не вызывать Show/Click напрямую. Tooltip инструмента может называться InfoPanelCloth — класс предмета определять по Item, не prefab.
- Перенос между Backpack и CoolBackpack, обмен Thatch/Log и обратный возврат прошли. Слоты и содержимое не кешировать.
- Split: Resource/Consumable, quantity>1, вне Belt, свободная ячейка в полном текущем хранилище. Slider, отмена, подтверждение и merge проверены на Trash4→2+2→4. Вторая часть попала в первую пустую Backpack7, хотя исходный стек был в CoolBackpack. Сумма по UID сохраняется; назначение второй ячейки наблюдать, не предполагать.
- В инвентаре Use инструмента означает экипировку, а не мировую атаку/бросок. WoodenHook обменялся с Rifle в Belt0, обратный Use восстановил оружие и прочность. Для текущего кода Tools/Weapon идут в Belt1 лишь при занятом0/пустом1, иначе0. Перед Use проверить отсутствие активного LongUnlock: он меняет эффект действия.
- Use воды/еды: ровно1Bottle и1Canned израсходованы; Thirst38→53, затем Hunger65→95/Thirst53→68. Для нового прогона нужны свежие количества/характеристики и разрешённая область расхода; исторические цифры не параметры.
- Remove открывает ДА/НЕТ. Отмена сохраняет стек. Подтверждение удаляет ВЕСЬ выбранный стек: для учебного удаления сначала выделена и проверена Trash1, итоговая сумма уменьшилась ровно на1.
- Sort и Remove взаимоисключающе показаны в `ActionWithItemsView`. Сортировка доступна при отсутствии подходящего выбранного предмета; два направления проверены, UID/count/dur сохранены. Sort может объединять стаки и меняет раскладку, поэтому один порядок иконок не является проверкой целостности.
- Заблокированная Tab2 открыла предложение+15ячеек/500дублонов; Close вернул инвентарь без покупки/изменения валюты. Заблокированный Extend slot — другая функция: режим Video может сразу запускать RV, его этим тестом не проверяли.

## Применение и остановки

Один отдельный исполнитель Unity MCP; координатор выбирает цель и пакет без Unity. Переиспользовать только нужный мотор и снимок; выполнять и компилировать команды при первом использовании. Движение/нажатия идут по реальным кадрам; состав и эффект сверяются после смысловой операции, не полным скриншотом на каждый клик.

`not_sent_covered`/`not_sent_missing` не позволяют идти к зависимому slider/confirm. Проверить фактический blocker и ограниченно ждать готовности; повтор возможен только при доказанном отсутствии ввода. Снимки null-safe. Новая неожиданная Console ошибка/неизвестный исход — остановка, наблюдение и cleanup. Старые исключения не наследуются. После вмешательства/паузы взять свежий baseline; неизвестную старую дельту сохранить без выдуманной причины и не приписывать новому действию.

Итог текущей сессии: инвентарь открыт, held/active/cycle=false, background восстановлен, watcher disarmed. Намеренные дельты только -1Bottle/-1Canned/-1Trash относительно свежего допуска; другие предметы/прочность/валюта сохранены.

Рабочие исходники сохранены как [экспериментальные примитивы](../../tools/inventory-learning/README.md): click, hold, drag, probe и снимки. Это мотор под управлением единственного MCP исполнителя, не автономный тест и не зарегистрированный approved handler. Перед использованием скопировать код в новый локальный evidence каталог, не писать логи в tracked исходники. Новые расход/удаление требуют применимой текущей задачи; старое разрешение не переносится из этой карточки.
