# ON-MECH-PICKUP-001 — подбор рукой

Игра: Ocean Nomad 2.11.0 dev, Unity Editor. Статус: **provisional**. Механика проверена по исходникам 23.10.2026; полный агентный сбор ещё не проверен.

## Доступность действия

Штатное действие `Pickup` выбирает цель по направлению из центра игровой камеры. Нужны подходящий коллайдер в пределах действующих дистанции/маски и `CanPickup=true`; в режиме строительства действие недоступно. Близость к transform объекта сама по себе недостаточна.

В сериализованных настройках Distance=2 unity units, маска Item; текущую runtime-конфигурацию проверять отдельно. Луч может иметь fallback spherecast радиусом0,5 на половину дистанции и отдельный путь по marker-mask. Это не означает видимость через геометрию всех остальных слоёв. Точный выбранный объект предпочтительно читать из текущей цели Pickup, не выводить из одной иконки.

Проверка цели обновляется раз в20 вызовов `Check`, не обязательно20 кадров. Между ними состояние может быть прежним. После перемещения отпустить ввод, дождаться актуального `Controll.Action.Pickup` и сопоставления с нужной целью. Основная кнопка контекстная: в предыдущем эпизоде она была `Controll.Action.Pistol` при отсутствии доступного ресурса.

Тап по объекту в мире — отдельный вариант взаимодействия: при некоторых условиях он запускает автоподход, а с плота с крюком может выбрать бросок крюка. Его не подменять основным путём обучения руки. Встроенный автоподход прямой; найденного обхода препятствий этот код не предоставляет. Условие свежего старта без крюка хранится в [ON-GAME-NEW-SURVIVAL-001](../world/ON-GAME-NEW-SURVIVAL-001.md); для hands_collect нужен подход и ручной сбор.

## Подтверждение сбора

Наблюдать правильный UID/экземпляр → доступный Pickup → штатное действие → изменение состояния этой цели → нужный прогресс. `ObjectCollect` отправляется **до** подтверждения достаточного места/выдачи предметов. Поэтому событие или счётчик2/2 отдельно не доказывают фактический сбор. При проверке награды дополнительно сверять ожидаемый прирост инвентаря.

Человек подтвердил успешный ручной сбор обоих ресурсов в демонстрации Hand_collect23.10.2026. Это человеческий пример; отсутствие телеметрии выбранной цели/завершения в журнале не позволяет независимо проверить результат. Подробности эпизода — в карточке миссии.
