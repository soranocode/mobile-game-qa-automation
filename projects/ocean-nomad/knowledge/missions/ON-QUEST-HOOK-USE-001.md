## Порядок и цель

Правило человека23.10: сначала изготовить крюк по [wooden_hook](ON-QUEST-WOODEN-HOOK-001.md), затем выполнять hook_use. Порядок вылавливания предметов не важен. Обратный порядок эпизодов записи — показ двух действий для обучения, а не маршрут прохождения.

Точный UID квеста hook_use (Hook_use — человеческое написание); шаг use_wooden_hook, тип ObjectCollect, Need3. Целевые типы: LogTutotial, BoxTutorial, BarrelTutorial. Не заменять их произвольными плавающими предметами. Деревянный крюк/его крафт — WoodenHook, это отдельный UID от квеста wooden_hook.

## Процедура кандидата

1. Изготовить и подготовить крюк; конкретный способ экипировки в этой записи не показан, наличие предмета в инвентаре само по себе не доказывает активный крюк.
2. При запросе тестового запуска использовать [TestGUI → Quests](ON-QUEST-START-001.json) с точным UID hook_use, секундными паузами и подтверждением смены панели; закрыть Назад до исчезновения панели, продолжить диалог.
3. Дать игре выполнить начальное наведение. Найти актуальные активные и не взятые цели из задания. Один раз составить очередь актуальных runtime ID; обновлять координаты, сохраняя выбранную цель до её сбора. Порядок не задан квестом, но внутри попытки очередь сохраняется по правилу человека ниже.
4. Навести камеру обычным Look. Сделать одно нажатие основной кнопки в контексте крюка по [механике](../mechanics/ON-MECH-HOOK-001.md). Проверить результат броска/возврата и прогресс. Не повторять нажатие во время незавершённого броска.
5. Повторять для оставшихся целей в любом порядке. При достаточной дальности не нужно идти в воду к предмету. Позиция демонстрации не является постоянной точкой.
6. Подтвердить новый итог3/3/завершение и сбор целей; историческое членство completed недостаточно. Снимки могут пропустить последнее значение — не выдавать исчезновение квеста/целей за самостоятельное полное доказательство.

Текущий исполнитель hook-trial.mjs проверен двумя полными прогонами с подтверждённым3/3 и принят человеком. Область — hook_use в этом Editor-билде; общая дальность/навигация для других сцен не объявляются освоенными. История первого медленного прогона сохранена ниже.
