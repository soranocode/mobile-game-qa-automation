# ON-QUEST-HANDS-COLLECT-001 — первый пространственный учебный кейс

Игра: Ocean Nomad 2.11.0 dev, Unity Editor. Приоритет человека23.10.2026: ориентация, поиск решения, движение и взаимодействие — основное направление обучения. Статус: **provisional**; описание и условия изучены, полное агентное прохождение не подтверждено.

## Цель и контекст

Собрать два нужных учебных ресурса обычным управлением из текущего состояния мира. UID миссии `hands_collect`, шаг `res_collected`, требуемый прогресс2. Предметы описаны один раз в ON-OBJ-TUTORIAL-RESOURCES-001; механика подбора — ON-MECH-PICKUP-001. Стартовое условие и обязательный сбор руками — [ON-GAME-NEW-SURVIVAL-001](../world/ON-GAME-NEW-SURVIVAL-001.md); крюк не является способом прохождения этого кейса.

Вызов через TestGUI/Quests — отдельный подготовительный навык ON-QUEST-START-001. После выбора закрыть панель через Назад до её исчезновения (1–2 уровня по текущей глубине), подтвердить начальный диалог доступной кнопкой продолжения. Человек называет её «Продолжить», в прошлом эпизоде было «ЗАКРЫТЬ»; журнал последнего клика записывает DialogChoiceButton без текста. Не привязывать маршрут к единственной надписи. Исходную блокировку прошлого запуска рассматривать по ON-LIMIT-QUEST-OBJECT-STATE-001.

## Решение по свежему состоянию

1. **Использовать начальное наведение.** По [ON-MECH-GUIDED-CAMERA-001](../mechanics/ON-MECH-GUIDED-CAMERA-001.md) дать игре закончить поворот после диалога. Затем различить нужный UID и конкретный экземпляр; проверить активность/взятость, относительное положение, нахождение в кадре и перекрытия. Если цель уже определена, сразу перейти к подходу. При необходимости найти её ручным обзором; неактивную цель диагностировать. Пустой результат с неизвестным покрытием не доказывает отсутствия.
2. **Выбрать подход.** По ON-WORLD-RAFT-001 найти позицию на доступной опоре, откуда ресурс будет в рабочей зоне Pickup. Оценить проход, край и препятствия. Ближайший по прямой ресурс может требовать более трудного подхода. Позиция плавающего ресурса не является целью ходьбы.
3. **Подойти.** Использовать короткие проверяемые движения по ON-CONTROL-MOVE-LOOK-001. После каждого обновлять положение цели/игрока и условия пути. При отсутствии прогресса остановиться, выбрать иной подход; неизвестный переход в воду/прыжок передать как потребность в новом навыке.
4. **Навестись и взаимодействовать.** Отпустить движение, навести камеру на нужный коллайдер, дождаться актуального Pickup и проверить совпадение выбранной цели. Другой контекст основной кнопки означает необходимость переоценки. Выполнить обычное действие.
5. **Проверить результат.** Сопоставить изменение состояния именно этого объекта и нужный прогресс; при проверке награды также инвентарь. Если действие не дало результата, разобрать дальность/наведение/перекрытие/вместимость/смену цели. Не повторять клик без обновления состояния.
6. **Повторить для оставшегося.** Найти следующий ещё не собранный экземпляр. Итог: оба нужных объекта фактически собраны, новый прогресс2/2 и завершение квеста подтверждены. Старый completed-флаг и один ранний ObjectCollect недостаточны.

## Что должен возвращать будущий компактный наблюдатель

Один согласованный frame/time/session; состояние миссии/окон/фокуса; игрок, опора и камера; только нужные цели с UID/instanceID, активностью, положением и системой координат, видимостью/доступностью; выбранное UI-действие и его текущая цель; ближайшие ограничения прохода и края; сигнал новой ошибки. Неизвестное обозначать явно. На этой основе локальный исполнитель может корректировать моторные действия, не перечитывая весь справочник и не вызывая модель на каждый кадр.

С23.10 частичный пассивный модуль пакета0.2.0 сохраняет квест/шаг/UID целей, прогресс, состояние и координаты соответствующих загруженных предметов, дистанции и геометрические поправки взгляда: [ON-OBS-QUEST-WORLD-001](../observation/ON-OBS-QUEST-WORLD-001.md). Полный согласованный наблюдатель видимости/поверхностей/проходимости, поиск пути, текущая цель Pickup и замкнутый моторный контроллер **ещё не реализованы**. Новый модуль не равен готовому навигационному навыку; реальная игровая демонстрация новой версии пока не проверена.

## Учиться по этапам

Сначала воспроизводимое исходное состояние и распознавание целей без движения. Затем подход к одному ресурсу с сохранением опоры. Затем полный подбор этого ресурса. После этого — оба ресурса с другим стартовым взглядом/положением, учитывая ограничения текущих навыков. Для каждого этапа отдельно фиксировать помощь человека, время и неудачи. Нового агентного прогона23.10 не было.
