# ON-QUEST-CANNED-EAT-001 — съесть консервы

29.10.2026. Ocean Nomad 2.11.0 dev, Unity Editor. Статус: HUMAN_APPROVED_SCOPED. Агент подтвердил прохождение и результат; человек посмотрел ускоренный повтор и одобрил его скорость. Перенос этого маршрута в общий каталог проверяется отдельно офлайн и не считается новым игровым прогоном.

## Миссия и используемые навыки

UID миссии и шага: `canned_eat`. Тип шага: `EQuestStepType.ItemUse` (4), предмет `Canned`, Need1. Наличие консервов и старый Done не доказывают завершение.

Миссия использует уже изученный [навык инвентаря](../ui/ON-UI-INVENTORY-001.md): открыть Backpack → найти актуальный `Canned` по UID/слоту → выбрать → проверить отсутствие LongUnlock → обычный Use ровно один раз. Новый способ кликов/переучивание инвентаря не требуются. Дельта количества подтверждает действие навыка, свежий Done нужного quest instance подтверждает миссию.

Дополнительно используется ON-QUEST-START-001 для тестовой активации: dev-панель → Quests → `canned_eat`, затем Назад до закрытия и известный Continue при наличии. CompleteQuests и прямые сигналы запуска/завершения не подменяют прохождение. Пауза внутри чит-панели1с, ввод по реальным кадрам. По указанию человека строка находится на странице6; при другом разрешении/составе панели страница может измениться, проверять подпись UID и текущую раскладку. Страница — подсказка поиска, не сохранённая точка экрана.

## Место в онборде

Человек указал релизный переход `hook_use → canned_eat`. Локальный `QuestChainDatabase.asset` подтверждает ребро Node3 (`hook_use`) → Node173 (`canned_eat`). Это новая известная связь порядка; последующая миссия после canned_eat этим указанием не задана. Прогон через читы не доказывает сам естественный переход после hook_use.

## Предусловия и критерии

- Актуальная задача человека, один отдельный исполнитель Unity MCP, свежие Game/owner/error-watch.
- Если canned_eat уже активна, не перезапускать. Иначе обычный выбор её строки в Quests; наблюдатель текущего экземпляра установить до расхода.
- После запуска/диалога заново прочитать Canned в инвентаре. Если его нет, вернуть предусловие; не выдавать предмет кодом и не переключать бесплатные читы.
- Use один раз. Подтвердить текущую дельту Canned-1, затем fresh Done с quest_uid=canned_eat, шаг1/1 IsComplete=true. Не повторять отправленный Use из-за задержки UI.
- Закрыть Backpack, отпустить ввод, сохранить текущую экипировку. При неожиданной ошибке/неизвестном исходе остановить ввод и разобраться до восстановления; исключения прежних задач не наследуются.
- Конкретный предмет в руке не является предусловием этой миссии. Читать и сохранять текущую экипировку; не восстанавливать её по старому снимку.

## Реализация и ограничения

Постоянные исходники миссии: `projects/ocean-nomad/tools/canned-eat/`. Точка регистрации: `factory.mjs#prepareCannedEatMission`; выполнение: `run.mjs#runCannedEat`, общий вызов — `qa.prepareMissions(['canned_eat'])`, затем `qa.runPipeline` по актуальному запросу человека. Регистрация создаёт локальный handler; рабочие Unity-команды выполняются и компилируются при первом использовании. Отдельную предварительную стадию не добавлять.

Миссия использует тот же `inventory-learning/motor.mjs` и общий `inventory-actions.mjs`, а не копию навыка. Адаптер Quests ограничен `canned_eat`; поиск опирается на UID, текущую раскладку и обычные кнопки страниц. Нужные шаблоны и параметры лежат рядом с миссией. Список окон не превращается в разрешение пропускать неизвестный UI.
