## Изученный семантический путь

1. Для тестового запуска выбрать Quests → wooden_hook по [навыку запуска](ON-QUEST-START-001.json), закрыть панель Назад, продолжить диалог.
2. Открыть крафт из HUD: UIHudInterfaceCraft. В эпизоде предварительно был клик по UIIndicationHighlightEmpty; его назначение по одному пути неизвестно, не считать обязательным шагом.
3. Убедиться, что текущий рецепт именно WoodenHook. Квест запускает штатный FocusCraftRecipeTrigger с этим UID, поэтому в демонстрации отдельный ручной выбор рецепта не виден. Автовыбор не предполагать для произвольного открытия крафта без квеста.
4. Нажать обычную кнопку изготовления UIButtonCraftCommon в панели выбранного рецепта. Не использовать частные Craft callbacks, выдачу предмета или завершение через CompleteQuests.
5. Проверить шаг1/1 IsComplete=true и результат создания, затем закрыть окно крафта RootNavigationWidget/CloseButton. Проверка инвентаря остаётся отдельной: текущий модуль его не записывает.
6. Подготовить изготовленный крюк для hook_use; способ смены экипировки следует изучить по фактическому UI при необходимости, а не придумывать по записи.
