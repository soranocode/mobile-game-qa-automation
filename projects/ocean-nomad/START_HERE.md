# Ocean Nomad в Unity Editor

1. [Восстановить среду](../../docs/RESTORE_ON_NEW_PC.md).
2. [Передать знания агенту](../../docs/AGENT_HANDOFF.md).

[Онборд одной последовательностью](../../brain/agents/ONBOARDING_RUN.md). Подготовка не запускает новую игру; запись демонстрации начинает человек. Неполный/неизвестный результат возвращается как NEEDS_REVIEW.
