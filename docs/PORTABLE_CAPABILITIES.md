# Состав перенесённых возможностей

28.10.2026. Окружение восстанавливается по RESTORE_ON_NEW_PC.md; правила поведения нового Codex — AGENT_HANDOFF.md. Сохранение исходника не повышает статус его игровой проверки.

- Вход и закрытие стартовых окон: ON-UI-ENTRY-001 и восстановленный tools/unity-entry/startup-control.cs.txt. Примитивы проверялись ранее; новая упаковка с error guard требует отдельного живого подтверждения. Агент принимает решения по текущему UI, универсального фиксированного cold-start runner нет.
- Настройки и маршруты UI: fast-ui/approved-skills.json, approved-ui.mjs, SettingsAdapter. Сохранены изученные назначения кнопок, доступ к настройкам из разных состояний, проверка значений/восстановления, новая игра и выход в меню. Физический эффект каждой настройки отдельно не подтверждён.
- Миссии онборда: общий каталог и пять handlers. Точные статусы — PREPARED_MISSIONS.md; hands_collect отложена. Весь расширенный набор одним прогоном не подтверждён.
- Крючок и очередь целей: fast-spatial, одобренный scoped навык. Новые координаты и фактический сбор определяются заново.
- Навигация: raft-navigation, компактная геометрия настила, безопасные участки и препятствия, ограниченный обычный мотор. Успех на прежнем плоту не доказывает произвольный маршрут на новом острове.
- Отражение угрозы: shark-defense, пассивный наблюдатель сигнала, подход/наведение/атака, отдельные контракты ближнего и дальнего боя. Полный цикл прерывания любой задачи и её универсального возобновления ещё не подтверждён.
- QA Demonstration: отдельный подключаемый Unity пакет, видео и действия, расширяемая телеметрия и офлайн анализатор. Нужна локальная установка в каждую копию игры.
- Память и роли: восемь коротких пакетов, индекс/карточки, проверка ревизий, шесть профилей Codex и профиль Cursor. Пул хранит готовые команды без фоновых ходов модели; глобальные разрешения не переносятся.
- Конвейер: подготовка двух следующих пакетов без MCP во время текущей миссии, один владелец и baseline ошибок на весь цикл, асинхронный журнал и итоговый анализ. Предложения PROPOSED привязаны к владельцам знаний; активная память не меняется. Код и границы отмены проверены офлайн, игровой замер ещё нужен. Описание — brain/agents/PIPELINE.md.

В Git не входят игра и её закрытые зависимости, сырые записи, состояние PlayerPrefs, активные угрозы, токены и процессы. Внешняя память и код воспроизводят изученные способы действий; их применимость к новой сборке проверяется отдельно.
