# Проверка переносимого комплекта

27.10.2026. Окружение: Windows, Python 3.12.10, Node 24.18.0, Unity 6000.0.66f2. Игровые прогоны во время упаковки не запускались.

Проверено:

- Индекс знаний и восемь коротких пакетов проходят проверку наличия источников и SHA256. Окончания строк зафиксированы как LF, чтобы повторное клонирование на другом ПК не ломало ревизии.
- Офлайн набор: 111 тестов JavaScript успешно; 58 тестов Python, два пропуска среды, остальные успешно. Покрываются память, контроллеры, отмена, рекордер/установка, планировщик и границы локального bootstrap.
- Шесть C# сниппетов, включая восстановленный примитив входа, скомпилированы против 499 существующих ссылок текущего Unity проекта. Проверка API/типов не заменяет игровой результат; error watcher в этом виде проверки заменён stub.
- Новый openRuntime подключился к ожидаемому локальному Unity проекту. Проверены свободный владелец ввода и возможность восстановить сессию; Play и миссии не запускались.
- Машинная конфигурация и рабочие пакеты исключены из Git. Игровые исходники, записи и данные авторизации в комплект не входят.
- Отдельный чистый локальный clone коммита `19df71a` прошёл тот же полный офлайн набор. Пакеты построены заново из файлов клона, без qa.local.json, прежних кешей и контекста чата. Это подтверждает комплектность исходников, а не установку на другом физическом ПК.

Команда повторения проверки: `python tools/portable/verify_offline.py`. Она создаёт локальный отчёт `brain-store/portable-runtime/offline-verification.json`; исходные видео и журналы прошлых эпизодов остаются отдельно.

Установка на другом физическом компьютере и первый игровой smoke после переноса остаются отдельной проверкой. Сам факт успешного clone или прохождения unit tests не подтверждает готовность всех миссий в новой среде.

## Конвейер, 28.10.2026

После внедрения очереди с параллельной подготовкой полный офлайн набор пройден: 149 JavaScript тестов, 58 Python тестов (два пропуска среды), все восемь пакетов актуальны. Проверены перекрытие подготовки с исполнением, порядок переходов, фиксированные ревизии, стоп между миссиями, поздние callbacks, сбой журнала и отсутствие ложного PASS при сбое финализации.

Имитация Unity также проверяет непрерывный baseline ошибок между миссиями, потерю подтверждения старта/завершения, удержание блокировки до подтверждённого cleanup и объединение одновременных запросов восстановления в один. Это проверка проектного API, а не отдельной песочницы.

11 C# сниппетов, включая пять команд управления циклом, скомпилированы против 499 ссылок Unity/игры. Сохранилось прежнее предупреждение unreachable code в примитиве входа; ошибок компиляции нет. Транспорт не подключался, Play и миссии не запускались. Реальное ускорение новой обвязки и полный игровой прогон остаются непроверенными.

Чистый локальный clone коммита `c9ace13` также прошёл полный набор: 149 JavaScript тестов и 58 Python тестов с двумя пропусками, пакеты построены заново без qa.local.json. Первая вложенная копия упёрлась в длину пути Windows при создании тестового кеша; копия в коротком каталоге прошла. На Windows для переноса выбирать короткий корневой путь. Другой физический ПК этой проверкой не покрыт.
