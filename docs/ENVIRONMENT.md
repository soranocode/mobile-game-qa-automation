# Среда пилота

Текущий этап — подготовка. Подключение телефона и игровые действия отложены по просьбе пользователя. Создание виртуальной среды не запускает ADB и не является игровым прогоном.

## Состав

- Windows и Python 3.10+; на первом компьютере использован Python 3.12.
- Android SDK Platform-Tools / ADB должны быть установлены отдельно для практического этапа. На первом компьютере они уже были доступны.
- Изолированная Python-среда `.venv` создаётся локально в корне репозитория; в Git не включается.
- Общий код: `tools/android/android_qa.py`. Проектные инструкции: `projects/ocean-nomad/`.
- Codex и Cursor работают с одной папкой проекта. Автоматическая передача истории между ними не настроена.

Для текущего моста не нужны pip, Airtest, Appium, Unity, Unity MCP или API-ключ. Дополнительные зависимости добавляем после того, как найдём конкретное ограничение первого примера.

## Подготовка среды

Из корня проекта:

```powershell
& .\scripts\prepare_environment.ps1
```

Скрипт создаёт среду без pip и без загрузок из интернета. Повторный запуск использует существующую среду. Глобальные настройки Python, Cursor, Codex и PowerShell не меняет. Политику выполнения PowerShell менять не требуется: если запуск `.ps1` запрещён на другом компьютере, эквивалентная команда подготовки:

```powershell
python -m venv --without-pip .\.venv
```

Активация среды не обязательна. В дальнейшем команды можно вызывать полным путём к интерпретатору:

```powershell
& .\.venv\Scripts\python.exe .\tools\android\android_qa.py <команда>
```

Это справочный синтаксис. Команды устройства запускаем только на практическом этапе.

## Что подготовить со стороны QA до прогона

1. Выбрать короткую миссию и переписать её точный текст. Текущая цель — онбординг Ocean Nomad; конкретная миссия ещё не выбрана.
2. Описать наблюдаемый признак завершения и возможные признаки ошибки.
3. Определить, как возвращаться в одинаковое начало: тестовый аккаунт, слот или штатный сброс обучения. Наличие такого способа ещё не подтверждено. Не стирать данные приложения ради эксперимента.
4. Записать версию билда, язык игры и условия сети для сравнимых попыток.
5. Выбрать одну роль для управления телефоном: Codex либо Cursor. Другой агент в это время может работать с кодом и документами.

## Статус проверки

Подготовлен исходный код моста и инструкции. Техническая проверка пока не завершена: ранние проверки с имитацией устройства не были завершены из-за ограничений доступа к временным каталогам Windows. Успешных прогонов на Ocean Nomad нет. После просьбы пользователя отложить проверки новые тесты и команды ADB не запускались. Перенос в репозиторий не считается проверкой игрового сценария.

В начале практического этапа, после явного разрешения пользователя, нужно завершить локальную проверку кода и проверить поведение на конкретном Android. Созданная среда сама по себе не подтверждает работоспособность игрового сценария.
