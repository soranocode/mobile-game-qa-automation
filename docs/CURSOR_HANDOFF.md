# Работа Codex и Cursor с одним пилотом

Открой в Cursor корень клонированного репозитория `mobile-game-qa-automation`.

Общий код находится в `tools/android/`, документы — в `docs/` и `projects/`, локальная среда — в `.venv`. Для интерпретатора Python используй `.venv/Scripts/python.exe`. Активация PowerShell не обязательна. Все команды выполняются из корня репозитория.

Роли: Codex — постановка QA-сценария, анализ доказательств и итогов; Cursor — редактирование и развитие кода. На практическом этапе управляет телефоном один выбранный агент. Не запускайте их команды одновременно и не редактируйте один файл параллельно.

Общий контекст — сохранённые файлы. Доступа к истории другого чата или автоматического обмена сообщениями эта схема не создаёт. Для передачи результата достаточно сохранить правки, список изменённых файлов и короткую заметку в чате.

## Текст для Cursor на текущем этапе

> Работаем над пилотом QA онбординга Ocean Nomad без исходников: готовый Android-билд, Python + ADB, решения по скриншотам. Прочитай AGENTS.md, README.md, docs/ENVIRONMENT.md, projects/ocean-nomad/PLAN.md и projects/ocean-nomad/START_HERE.md. Сейчас разрешена только подготовка среды, кода и документации, а также управление репозиторием по запросу пользователя. Пользователь отложил проверки: не вызывай ADB, не проверяй подключение, не запускай локальные или игровые тесты, не управляй телефоном. Не устанавливай дополнительные зависимости без конкретной причины. Не меняй глобальные настройки и не добавляй API-интеграцию. Если предлагаешь изменения кода, опиши их и сохрани минимальные правки. Не утверждай, что тесты пройдены или миссия работает. Дальнейшая проверка начинается после явного перехода пользователя к практическому этапу.

## Перед передачей управления на практическом этапе

Записать папку сессии, реальный пакет игры, устройство, билд, миссию, критерий завершения и последнюю выполненную команду. В новом чате начинать с актуального observe, а не с повторения предыдущего ввода. projects/ocean-nomad/PROMPT_FOR_CODEX.md применяется только после перехода к практическому этапу.
