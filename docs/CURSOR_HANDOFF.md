# Совместная работа Codex и Cursor

Открывать корень этого репозитория автоматизации. Работаем с Unity Editor; текущий комплект и восстановление описаны в [RESTORE_ON_NEW_PC](RESTORE_ON_NEW_PC.md).

Общий опыт — код, карточки и проверенные пакеты в файлах. Автоматической синхронизации истории чатов нет. Cursor может редактировать или анализировать отдельный модуль, пока назначенный Codex владеет игровым вводом. Не редактировать один файл одновременно и не создавать второго контроллера Unity.

Для нового помощника: прочитать AGENTS.md и docs/AGENT_HANDOFF.md, получить одну конкретную подзадачу. Для знакомого повтора использовать dispatcher/готовый handler. Не восстанавливать архитектуру из архивов и не запускать игру по историческому сообщению.
