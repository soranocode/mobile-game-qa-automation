# Передача работы Cursor

Область: код автоматизации Unity Editor, разбор ошибок, ревью и предложения тестов. Координатор выбирает самостоятельную подзадачу; Cursor получает только её цель, критерии и выбранные файлы. Переписка и весь игровой справочник не пересылаются.

Используется установленный Cursor CLI и его обычная авторизация. Дополнительный SDK и отдельный ключ в проекте не нужны. Модель выбирается настройками Cursor; мост её не переопределяет. CLI запускается в отдельной папке со снимками выбранных файлов. Основная рабочая папка может содержать незавершённые правки других агентов.

## Как передать задачу

Из корня репозитория:

```powershell
python tools/cursor-bridge/delegate.py prepare --goal "Проверь обработку отмены и предложи исправление" --file tools/agent-runtime/mission-pool.mjs --criterion "Назови конкретную ошибку или верни отсутствие подтверждённых проблем"
python tools/cursor-bridge/delegate.py run TASK_ID
python tools/cursor-bridge/delegate.py show TASK_ID
```

`prepare` возвращает TASK_ID и ничего не отправляет. `run` передаёт задачу Cursor и возвращает результат. Для длительного вызова координатор читает завершение процесса, продолжая независимую работу; второй запуск того же задания запрещён. Это передача работы через CLI, а не сообщение в уже открытый чат Cursor IDE.

Cursor возвращает JSON с кратким итогом, прочитанными файлами, находками, предлагаемым diff и непроведёнными проверками. Результат всегда остаётся предложением. Координатор сверяет хеши исходников, читает diff, применяет нужную правку и запускает подходящие проверки. Изменившийся исходник делает предложение устаревшим; успех процесса сам по себе не подтверждает правильность кода или прохождение игры.

## Роли и ограничения

- Координатор ставит цель, выбирает файлы, принимает и проверяет предложение.
- Cursor работает с одним пакетом; может анализировать код и предлагать реализацию или тесты.
- Отдельный игровой исполнитель остаётся единственным владельцем Unity/MCP. Cursor не запускает игру.
- Память обновляется у владельца знания после проверки и применимого апрува. Cursor не меняет критерии успеха или статусы игровых навыков.

В пакете до 12 текстовых файлов и 96 КБ исходников. Архивы чатов, локальные параметры, секреты, сырые доказательства и соседний игровой проект не копируются. Для задания установлены запреты shell, записи, веб-доступа и MCP; эти настройки инструментов не являются отдельной гарантией изоляции всей ОС. В текущем варианте Cursor предлагает изменения, не редактирует общий checkout.

Установленная версия CLI не поддерживает отдельную OS sandbox на Windows. Мост не меняет глобальные настройки и использует обычную политику CLI с указанными запретами в папке задания. На поддерживаемых ОС передаётся `--sandbox enabled`.

Задания, ответы, stderr и снимки находятся в игнорируемом `brain-store/cursor-tasks/TASK_ID/`. В Git сохраняются только мост, профиль и инструкция. При таймауте или неизвестном результате сначала изучить сохранённый итог; автоматических повторов нет. Пропущенный контекст возвращается как `needs_context`, не как выдуманная реализация.

Если процесс успешно завершился, но старая версия парсера не приняла формат, `python tools/cursor-bridge/delegate.py reconcile TASK_ID` повторно разбирает сохранённый ответ без нового вызова Cursor. Для таймаута или неподтверждённого завершения эта команда запрещена.

Профиль: `.cursor/agents/ocean-code-worker.md`. В отдельном снимке он используется как AGENTS.md, поэтому работа не зависит от наличия старого чата или автоматического обнаружения профиля IDE.

## Проверки и источники

```powershell
python -m unittest discover -s tools/cursor-bridge -p test_*.py
```

Офлайн-тесты проверяют выборку файлов, запреты, устаревание, результат, изменение снимка и отсутствие повторного вызова. Они не заменяют проверку настоящего соединения Cursor и не запускают Unity.

31.10.2026: 13 офлайн-тестов прошли. Настоящий вызов установленного CLI 2026.10.19-6bbf2c4 вернул предложение о границах ролей по выбранному профилю, с конкретными ссылками на его строки. Принятие формата подтверждено повторным разбором сохранённого успешного ответа: CLI объединяет промежуточный текст с финальным JSON. Это проверка передачи небольшого задания, не доказательство качества будущих патчей или игрового результата. Также сохранены неудачные попытки с ограничением доступа, неподдерживаемой песочницей и таймаутом; стабильная скорость CLI пока не подтверждена. Для одного успешного процесса полное время составило 74.4 с, поэтому Cursor предназначен для параллельной работы с кодом, не отдельных игровых кликов.

Проверенные параметры CLI и формат ответа: [Cursor Headless](https://cursor.com/docs/cli/headless), [JSON output](https://cursor.com/docs/cli/reference/output-format). Права инструментов: [Cursor Permissions](https://cursor.com/docs/cli/reference/permissions).
