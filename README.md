# Unity QA Automation

Автотесты Ocean Nomad в Unity Editor через MCP. В репозитории сохраняются проверенные знания, код навыков, исполнители сценариев, QA Demonstration и роли агентов. Рабочая ветка комплекта: `docs/game-brain-architecture`.

## Начать на другом компьютере

1. Клонировать эту ветку и открыть **корень этого репозитория** как проект Codex.
2. Следовать [RESTORE_ON_NEW_PC](docs/RESTORE_ON_NEW_PC.md).
3. Передать новому Codex [AGENT_HANDOFF](docs/AGENT_HANDOFF.md). Для знакомого повтора не читать архивы.

```powershell
git clone --branch docs/game-brain-architecture https://github.com/soranocode/mobile-game-qa-automation.git
cd mobile-game-qa-automation
python tools/portable/bootstrap.py check
```

Последняя команда проверяет комплект и память офлайн, без Unity и игровых действий. Машинные пути задаются отдельно в игнорируемом `qa.local.json`.

## Что переносится

- `projects/ocean-nomad/knowledge/` — индекс и тематические карточки с источниками, статусами и ограничениями.
- `projects/ocean-nomad/tools/` — повторно используемые UI, пространственные и боевые действия.
- `tools/agent-runtime/` — подготовленные обработчики миссий, пул, очередь с параллельной подготовкой пакетов и итоговый анализ.
- `tools/unity-ui/`, `tools/unity-entry/` — транспорт, сессия, наблюдение ошибок и примитивы входа.
- `packages/com.gameqa.demonstrations/` — отдельный расширяемый Unity пакет записи видео, действий и телеметрии.
- `.codex/agents/`, `.cursor/agents/`, `.cursor/rules/` — роли и проектные правила; общий опыт хранится в файлах.
- `tools/portable/` — локальная конфигурация, проверка и единый bootstrap нового исполнителя.

Копия игры, её зависимости, лицензия Unity, локальные записи, сохранения, авторизация и прогретые процессы не входят в Git. Их подготовка и восстановление описаны в инструкции. Текущие координаты, итоги прежнего запуска и разрешения на ввод заново не используются.

## Текущий статус

Проверены отдельные UI сценарии, применение крюка, движение по плоту и отражение атаки. Подготовленная цепочка: `intro → control → wooden_hook → hook_use → shark_attack`; `hands_collect` отложена. Новые control/wooden_hook прошли и одобрены по скорости 27.10. Intro исправлен после подсказки Finish; автономный повтор после исправления ещё нужен. Полная цепочка из пяти новых обработчиков одним прогоном ещё не подтверждена.

Новый Codex получает те же сохранённые знания и код, а не копию контекста модели или гарантию идентичного поведения на любом билде. Различать описание навыка, офлайн проверку, реальный прогрев и успешный игровой результат.

## Работа

Для знакомой задачи: `python tools/knowledge/dispatch.py TASK --prepare`. Это короткая память, без игрового ввода. Новый процесс исполнителя поднимается через `tools/portable/runtime.mjs#openRuntime`; известные повторы используют `getRuntime()` и готовые handlers. Один исполнитель владеет Unity.

Инструкции: [последовательный онборд](brain/agents/ONBOARDING_RUN.md), [протокол ролей](brain/agents/PROTOCOL.md), [пополнение знаний](brain/KNOWLEDGE_WORKFLOW.md), [проверенные ограничения](tools/agent-runtime/PREPARED_MISSIONS.md).

Координатор и исполнитель — два отдельных агента. Координатор выбирает и готовит задачи без доступа к Unity; только назначенный `ocean-mcp-executor` держит runtime и отправляет команды. Профиль `ocean-coordinator`, точный протокол и текст для существующего чата — [ROLE_HANDOFF](brain/agents/ROLE_HANDOFF.md). Библиотека конвейера сама агентов не создаёт.

С 28.10 `qa.runPipeline` готовит следующие два пакета во время текущей миссии, сохраняет одного владельца ввода и наблюдателя ошибок между миссиями. Телеметрия собирается в процессе; общий анализ и предложения знаний формируются после цикла. Подробности — [конвейер](brain/agents/PIPELINE.md). Обвязка проверена офлайн; её скорость в реальной игре ещё не измерялась.

## Проверки без игры

```powershell
python tools/portable/verify_offline.py
```

Используются тестовые транспорты и локальные фикстуры. Play не запускается. Для игровых действий нужен актуальный запрос QA; старые сообщения и карточки сами по себе не разрешают запуск.
