# Mobile Game QA Automation

Общий репозиторий инструментов и сценариев для QA мобильных 3D-игр с помощью ИИ. Первый пилот — одна онбординг-миссия Ocean Nomad на Android без доступа к исходникам игры.

Долгосрочное направление — [игровой агент с памятью](brain/README.md): пространственное состояние, поиск знаний, планирование задач и накопление проверенного опыта. Нужная ветка исходников Unity доступна для просмотра в GitLab; по файлу проекта определена версия Editor: 6000.0.66f2. Локальное развёртывание проекта и подключение Unity MCP ещё не выполнены. Архитектура описана, само ядро пока не реализовано.

**Статус: подготовка.** Мост на Python написан, техническая проверка не завершена, успешных игровых прогонов пока нет. По текущей договорённости тесты, команды ADB и игровые действия отложены до явного перехода пользователя к практическому этапу.

## Структура

```text
tools/android/                 Общий мост: скриншоты, касания, свайпы, доказательства
brain/                        Архитектура агента, памяти и будущей Unity-интеграции
conversations/                Архивы диалогов и текущая точка продолжения между ПК
projects/ocean-nomad/          План и сценарий пилота онбординга
projects/ragdoll-sandbox/      Подготовка следующего игрового проекта
docs/                         Среда и совместная работа Codex/Cursor
scripts/                      Подготовка локального Python
AGENTS.md                     Общие инструкции для ИИ-агентов
```

## Начало работы

Открой корень репозитория в Cursor или Codex. Прочитай [правила работы](AGENTS.md), [текущую точку продолжения](conversations/CURRENT.md), [описание среды](docs/ENVIRONMENT.md), [план Ocean Nomad](projects/ocean-nomad/PLAN.md) и [инструкцию для Cursor](docs/CURSOR_HANDOFF.md).

Для работы с нескольких компьютеров используй [пространство диалогов](conversations/README.md): [указатель архивов](conversations/INDEX.md) и CURRENT.md. Они хранятся в Git; новые сообщения чата автоматически туда не добавляются. Сведения о доступе к Unity в старых планах и диалогах сверяй с CURRENT.md.

Требуется Python 3.10+; на первом компьютере использован Python 3.12. Подготовка изолированной среды из корня репозитория:

```powershell
& .\scripts\prepare_environment.ps1
```

Скрипт создаёт `.venv` без pip и загрузок из интернета. ADB и тесты он не запускает. Текущий мост использует только стандартную библиотеку Python. Platform-Tools потребуются на практическом этапе.

Игровые команды описаны в [инструкции Ocean Nomad](projects/ocean-nomad/START_HERE.md). Начало практического этапа должно быть явно подтверждено пользователем. MCP-сервер и самостоятельный запуск через API в текущую реализацию не входят.

## Несколько проектов

Каждой игре соответствует папка в `projects/`: цель пилота, условия старта, критерии завершения, план и инструкции. Общий код остаётся в `tools/`. Новая игра не должна требовать копирования общего Android-моста.

Результаты будущих прогонов сохраняются локально в `runs/<project>/<attempt>/`. Эта папка исключена из Git. Для проверок нужны реальный пакет игры, билд, выбранная миссия и одинаковое исходное состояние.

Будущая рабочая память хранится локально в `brain-store/`, также вне Git. Отобранные знания Ocean Nomad — в [projects/ocean-nomad/knowledge](projects/ocean-nomad/knowledge/README.md). Это хранилище пока не заполнено реальными игровыми знаниями.

## Изменения и совместная работа

Основная ветка — `main`. Для отдельной задачи создавай ветку, например `feature/ocean-nomad-onboarding`. Перед коммитом просматривай изменения; сохраняй небольшие законченные правки с понятным описанием. При командной работе предлагай изменения через pull request.

Codex и Cursor обмениваются контекстом через файлы репозитория. Во время будущего прогона телефон контролирует один агент. В итогах различай завершение миссии, подозрение на игровой дефект и ошибку самой автоматизации.

В Git храним код и документацию. Локальные среды, результаты прогонов, APK/AAB, ключи, `.env` и настройки устройств исключены через `.gitignore`. Лицензия на распространение кода пока не выбрана.
