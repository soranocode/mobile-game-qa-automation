# Точка продолжения на другом ПК

28.10.2026. Репозиторий подготовлен для переноса Unity автотестов, знаний и ролей. Первым делом — docs/RESTORE_ON_NEW_PC.md и docs/AGENT_HANDOFF.md. Рабочая ветка: docs/game-brain-architecture.

Уточнение человека: координатор и исполнитель должны быть разными агентами. Добавлен профиль ocean-coordinator и ROLE_HANDOFF.md. Родитель не вызывает Unity/MCP, включая наблюдение; явно создаёт/использует одного отдельного ocean-mcp-executor. Диспетчер различает необязательного специалиста памяти и обязательного отдельного исполнителя. Игровая библиотека конвейера сама агентов не создаёт. Проверка разделения выполняется на имитации, без Unity.

Репетиция: отдельный /root/qa_executor_rehearsal прошёл 30 тестов на имитации, координатор готовил intro/control без Unity. Затем тот же исполнитель прошёл полный набор: 149 JS + 60 Python (два пропуска). Квитанции локально в brain-store/role-rehearsal/. Нативная автозагрузка профиля и live прогон новой схемы не проверены. Старый чат координатора должен перечитать START_COORDINATOR.md/ROLE_HANDOFF.md; сама правка файлов не запускает его и не пересылает сообщений.

Реализовано согласованное распределение: во время текущей миссии готовятся следующие два пакета без MCP; один исполнитель сохраняет право ввода и baseline ошибок между миссиями. Общая аналитика и предложения `PROPOSED` формируются после цикла. Основной вызов — qa.runPipeline (runMissions alias), описание — brain/agents/PIPELINE.md. Команды Unity прогреваются заранее; активные версии не меняются. Новая обвязка проверена офлайн, без игровых действий; live замер ещё нужен.

Последние решения: строго Unity Editor; раздельные навыки и миссии; короткие пакеты вместо полной переписки; один исполнитель; прогрев до замера; объяснения после прогона. Последовательность онборда: intro → control → wooden_hook → hook_use → shark_attack. hands_collect отложена.

Новые control/wooden_hook прошли и одобрены по скорости. Intro исправлен после подсказки о последней Finish; автономный повтор после правки ещё нужен. Полная цепочка пяти новых handlers одним прогоном не подтверждена. Ввод предыдущих запусков завершён; состояние новой Unity не считать известным.

Долговременные знания находятся в тематических карточках и коде. После клонирования не искать прежние переменные REPL или локальные артефакты; восстановить runtime из tools/portable/runtime.mjs. Сырые видео, журналы, сохранения и прогретые процессы не переносились. Установка и офлайн проверки не разрешают новый игровой прогон.
