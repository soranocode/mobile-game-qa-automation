# Точка продолжения на другом ПК

27.10.2026. Репозиторий подготовлен для переноса Unity автотестов, знаний и ролей. Первым делом — docs/RESTORE_ON_NEW_PC.md и docs/AGENT_HANDOFF.md. Рабочая ветка: docs/game-brain-architecture.

Последние решения: строго Unity Editor; раздельные навыки и миссии; короткие пакеты вместо полной переписки; один исполнитель; прогрев до замера; объяснения после прогона. Последовательность онборда: intro → control → wooden_hook → hook_use → shark_attack. hands_collect отложена.

Новые control/wooden_hook прошли и одобрены по скорости. Intro исправлен после подсказки о последней Finish; автономный повтор после правки ещё нужен. Полная цепочка пяти новых handlers одним прогоном не подтверждена. Ввод предыдущих запусков завершён; состояние новой Unity не считать известным.

Долговременные знания находятся в тематических карточках и коде. После клонирования не искать прежние переменные REPL или локальные артефакты; восстановить runtime из tools/portable/runtime.mjs. Сырые видео, журналы, сохранения и прогретые процессы не переносились. Установка и офлайн проверки не разрешают новый игровой прогон.
