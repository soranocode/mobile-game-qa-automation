# Передача контекста

Для продолжения достаточно [CURRENT](CURRENT.md) и [памятки агенту](../docs/AGENT_HANDOFF.md). Полная история чатов не нужна для повторного выполнения изученных действий; знания сохранены в собственных карточках и исполняемых модулях.

Git переносит отобранные заметки и код. Открытый чат, будущие сообщения и сырые записи автоматически не синхронизируются. Исторические команды не разрешают новый ввод. Для сохранения нового опыта указать источник/билд/статус и обновить владельца знания по brain/KNOWLEDGE_WORKFLOW.md.
