# Технические проверки квестового и пространственного наблюдения

Содержимое .cs.txt передаётся в Unity MCP execute_code как C# method body. Требуется скомпилированный пакет0.2.0, Play/запись выключены. Скрипты сами это проверяют и не останавливают активную игру.

- quest-world.cs.txt:19проверок геометрии, неизвестных данных, чтения синтетических квестов, лимитов/усечения и однократной подписки lifecycle.
- spatial-frame.cs.txt:5проверок в отдельной preview-сцене: локальные координаты, ID опоры, collider aim, движение системы отсчёта, сохранение активной сцены/dirty. Создаются только синтетические GameObject/BoxCollider, игровые компоненты не создаются. Кэши адаптера временно подменяются и восстанавливаются в finally; preview-сцена и объекты удаляются.

Эти проверки не запускают Play, запись человека, квест или игровой ввод; прогресс/сохранения игры не меняются. Это технические fixtures, не доказательство самостоятельного прохождения или работы в реальной демонстрации. В этой установке две версии Newtonsoft мешают явным ссылкам на его типы при in-memory CodeDom компиляции, поэтому fixtures используют типы возвращённых значений и reflection; установленные assembly пакета компилируются штатно.
