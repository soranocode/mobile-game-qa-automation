# Вход через MCP

Здесь сохранён прежний примитив START и закрытия Mail/Premium/Discord из локального входа 21-22.10.2026. Восстановленный источник снабжён общим error watcher и guard прогрева; новая упаковка ещё не проверена живым повтором.

Семантика и область проверки — ON-UI-ENTRY-001. Это отдельный примитив, не фиксированный список окон и не универсальный cold-start runner. Ассистент выбирает действие по текущему интерфейсу; найденную доступную кнопку нажимает без повторного изучения её назначения. Точки экрана не переносятся.

В startup-control.cs.txt подставить __CONTROL__ одним из observe/setup_start/mail_close/premium_close/discord_close и __DISPATCH__ false для observe или true для выбранного действия. Затем использовать session.instrument(code) и execute_code через проверенное подключение/единственную сессию. Подготовка точных кодов выполняется с QaAgent.FastUi.warmup=true, исполнения — с false. После действия получить актуальное состояние, не повторять неизвестный исход.

Примитив не включает Play, не меняет сцену и не нажимает вход из главного меню. Для последнего есть изученная роль main_menu.enter_survival в карточке: найти актуальный control и использовать обычный selected-control/EventSystem. Сцену Setup/Play открывать только по актуальному запросу QA. На необычном окне вернуть управление агенту. Не переименовывать игровые prefab ID из-за содержащегося в них исторического суффикса.
